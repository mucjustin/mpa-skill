# MPA Knowledge Base

何时查阅：研究设计选择理论、案例分析定位情境、论文起草前校验思维、课程作业规划时读取。配合 `mpa-research-contract.md` 做契约校验、`routing.md` 做路由选择。

论文四类型：专题研究、案例分析、调研报告、公共政策分析。类型与既有研究契约的对应：专题研究=problem study、案例分析=case analysis、调研报告=survey report、公共政策分析=policy analysis。

## 理论地图

### 政策执行与基层

| 理论 | 核心命题 | 典型中国应用情境 | 适用论文类型 | 常见误用 |
|---|---|---|---|---|
| 政策执行理论（自上而下/自下而上） | 政策效果取决于执行机构、目标群体与政策文本的互动 | 基层政策落地偏差、政策试点推行 | 案例分析、调研报告 | 只列模型不加执行过程证据；只讲政策文本不讲执行偏差 |
| 压力型体制 | 指标—考核体系驱动基层动员与层层加压 | 中央政策在基层的层层加码、目标责任制 | 案例分析、专题研究 | 以体制解释一切基层行为，缺机制细节、不区分任务性质 |
| 街头官僚理论 | 一线执行者的裁量与偏好塑造政策现实 | 窗口服务、执法裁量、基层事务办理 | 案例分析、调研报告 | 忽略制度约束谈自由裁量 |
| 政策执行网络（府际关系） | 政策结果由多级政府互动塑造 | 央地事权划分、属地管理 | 专题研究、公共政策分析 | 单一层级视角看执行 |
| 政府职能理论 | 政府角色应随治理任务界定并动态调整 | 乡镇政府主导作用激活、政府职责界定 | 调研报告、案例分析 | 职能罗列与问题诊断脱节 |
| 运动式治理 | 非常规政治动员集中资源实现特定目标 | 专项行动、集中整治、攻坚克难 | 案例分析、专题研究 | 将常态治理与运动式治理混为一谈 |
| 目标责任制 | 目标分解与考核驱动基层执行行为 | 目标管理责任制、绩效考核体系 | 专题研究、调研报告 | 只看目标分解不看执行变形 |

### 制度与激励

| 理论 | 核心命题 | 典型中国应用情境 | 适用论文类型 | 常见误用 |
|---|---|---|---|---|
| 制度激励理论 | 激励结构塑造行为选择 | 绩效考核下的选择性执行 | 调研报告、公共政策分析 | 脱离现实制度约束谈最优设计 |
| 委托—代理理论 | 信息不对称下的激励与监督问题 | 政府购买服务中的监管 | 公共政策分析、案例分析 | 只讲模型不讲信息与合约细节 |
| 锦标赛体制 | 相对绩效考核驱动地方竞争 | 经济发展竞赛、达标评比 | 专题研究、公共政策分析 | 将竞争逻辑套用于所有领域 |
| 资源依赖理论 | 组织通过交换与控制关键资源维持生存与自主性 | 政府—社会组织关系、组织间资源交换 | 案例分析、专题研究 | 只谈依赖不谈权力与情境 |
| 新公共管理理论 | 政府"掌舵而非划桨"，引入竞争与绩效改进公共服务 | 政府购买服务、公共服务外包 | 调研报告、案例分析 | 只取"民营化/外包"口号，不界定政府职责与监管闭环 |
| 公共选择理论 | 理性人在政治与行政领域同样追求自身利益 | 官僚预算最大化、选民行为分析 | 公共政策分析、专题研究 | 将经济人假设泛化为所有人都自私 |

### 治理与制度主义

| 理论 | 核心命题 | 典型中国应用情境 | 适用论文类型 | 常见误用 |
|---|---|---|---|---|
| 多中心治理 | 多元主体协同解决公共问题 | 社区治理、公共事务共治 | 案例分析、调研报告 | 忽略政府主导地位谈多元 |
| 整体性治理 | 跨部门整合解决碎片化问题 | 一网通办、行政审批改革 | 公共政策分析、专题研究 | 把技术整合当作组织整合 |
| 制度变迁理论 | 制度在路径依赖与关键节点中演化 | 改革试点—推广的渐进变迁 | 专题研究、案例分析 | 忽略行动者与时机因素 |
| 协同治理/合作治理理论 | 多元主体通过制度安排实现共同目标 | 合作型治理结构、多元主体协同参与 | 专题研究、调研报告 | 把"协同"当口号，无结构与机制分析 |
| 治理结构理论 | 治理由结构（制度联结形态）与主体（行动者能力）共同塑造 | 结构变迁与主体强化的互动分析 | 专题研究 | 只描述结构不追问主体，割裂二者因果链 |
| 技术治理/智慧城市理论 | 数据与技术重构治理结构与主体关系，伴随数据依赖与风险 | 智慧政务平台、城市大脑建设 | 专题研究 | 技术决定论，忽视适用性与风险批判 |
| 福利多元主义 | 福利由国家、市场、家庭与社会组织共同供给 | 政府主导—多元主体参与的养老服务供给 | 调研报告、案例分析 | 罗列多元主体却不分析供给结构与责任分担 |
| 网络治理 | 治理网络中节点关系塑造公共产出 | 政府间协作网络、政社合作网络 | 专题研究、案例分析 | 只画网络图不分析关系机制 |
| 民主行政理论 | 公民参与和民主价值应进入行政过程 | 参与式预算、协商式治理 | 公共政策分析、案例分析 | 把参与等同于投票 |

### 政策过程

| 理论 | 核心命题 | 典型中国应用情境 | 适用论文类型 | 常见误用 |
|---|---|---|---|---|
| 政策议程设置（多源流） | 问题流、政策流、政治流交汇开启议程窗口 | 突发事件推动议题进入政策议程 | 公共政策分析、案例分析 | 把三流当清单而非互动过程；机械套用于微观行动层问题 |
| 政策工具理论 | 工具选择受目标、能力与情境约束 | 补贴、管制、信息工具的组合 | 公共政策分析、调研报告 | 脱离执行条件罗列工具 |
| 政策反馈理论 | 政策结果反塑政治与后续政策 | 试点经验、既有政策的学习效应 | 专题研究、公共政策分析 | 忽略反馈的层级与机制 |
| PPP（公私合作伙伴关系）理论 | 公私风险分担与全生命周期合作供给公共品 | 特许经营、基础设施与公共服务投融资 | 专题研究、公共政策分析 | 泛化为"一切政府—企业合作"，忽视契约与风险分配内核 |
| 政策终结理论 | 政策退出受沉没成本、政治可行性与替代方案影响 | 过时政策退出、机构改革 | 公共政策分析、专题研究 | 只讲政策出台不讲退出 |
| 间断均衡理论 | 政策长期稳定中穿插突变性变化 | 重大改革窗口、危机驱动政策跃迁 | 专题研究、公共政策分析 | 把渐进等同于稳定无变化 |

## 中国治理情境库

情境按治理场景分组；「代表案例」为公开可查的抽象化案例类别，供论文举例定位，不指向任何个人课题。与理论地图的「典型中国应用情境」列互指。

| 情境 | 特征 | 典型政策工具 | 论文切入视角 | 代表案例 |
|---|---|---|---|---|
| 央地关系与压力型体制 | 目标责任制、层层分解、督查考核、属地管理 | 督查、考核、问责、约谈 | 基层执行偏差如何产生、层层加码如何形成 | 政策执行阻滞研究、环保督察整改 |
| 政策试点—推广 | 先试点后推开、试验性治理、以点带面 | 试点名单、示范区、容错机制 | 试点经验如何扩散、为何有的试点失败 | 改革试验区、地方创新扩散 |
| 本土治理创新与群众路线 | 矛盾化解与政务服务改革构成理论修正的经验来源 | 流程再造、接诉即办式响应、协商调解 | 本土情境化理论修正视角 | 枫桥经验、接诉即办、最多跑一次 |
| 数字政府与数字治理 | 数据驱动、平台化、一网通办；存在数据依赖与"大数据傲慢"风险 | 政务平台、大数据监管、数据共享 | 技术赋能 vs 数字形式主义、结构与主体互动 | 一网通办实践、城市大脑 |
| 公共服务供给改革 | 政府购买服务、政社合作、监管易不闭环 | 购买服务目录、合同制、绩效考核 | 供给质量与监管缺口、满意度评估 | 政府购买养老服务、公共服务外包 |
| 基层治理与社区自治 | 党建引领、居民参与、资源下沉、行政化倾向 | 网格化、协商议事、矛盾调解 | 参与不足与行政化倾向 | 网格化管理、社区协商案例 |
| 应急管理与风险治理 | 非常态动员、跨部门协同、信息报送 | 应急预案、联防联控、信息报送 | 常态机制与非常态动员的衔接 | 突发公共卫生事件应对 |
| 乡村振兴与县域发展 | 县域统筹、乡镇政府主导、资源下乡、人才匮乏 | 转移支付、驻村帮扶、产业扶持、示范创建 | 政策资源落地与可持续性、政府职能与资源整合 | 乡村旅游开发、驻村帮扶、示范村创建 |
| 老龄化与养老服务供需 | 老龄化加速、需求多元而供给不足、队伍建设薄弱 | 居家养老服务补贴、多元主体协同供给 | 需求层次与福利多元供给视角 | 养老服务补贴政策、满意度调查 |
| 社会资本参与基础设施（PPP） | 公私合作供给公共品、风险分担、受政策节点驱动 | 特许经营、政府规制、风险防范机制 | 契约与风险分配、政策节点与实施效果联动 | 社会资本参与基础设施投资经营的实践 |
| 区域协同发展 | 跨行政区协作、利益协调、规划统筹 | 区域规划、产业分工、生态补偿 | 协作机制设计与利益博弈 | 京津冀协同、长三角一体化 |
| 营商环境优化 | 放管服改革、审批简化、事中事后监管 | 简政放权、负面清单、双随机一公开 | 政府效能提升与市场活力激发 | 营商环境条例实施、审批制度改革 |
| 生态环境治理 | 属地责任、督察问责、多元共治 | 环保督察、河湖长制、生态补偿 | 责任传导机制与治理效果 | 环保督察、河长制实施 |
| 数据治理与隐私保护 | 数据共享开放、安全合规、个人隐私 | 数据分类分级、安全审查、隐私影响评估 | 数据流动与安全平衡 | 政务数据共享、个人信息保护 |

## 公管思维清单

每次草稿验收、研究设计评审前用自查问题检验公管思维是否落地。反模式直接来源 MPA 论文四类型的常见误区。

| 思维原则 | 自查问题 | 论文落地方式 | 反模式 |
|---|---|---|---|
| 问题导向 | 我的论文解决谁的什么现实问题？能否一句话说清？ | 绪论从现实困境切入，按"问题意识—理论基础—成因剖析—对策建议"递进，问题、理论与素材保持同一层次 | 问题失焦：选题大而无当，问题被文献综述淹没 |
| 类型自觉 | 我的论文属于四类型中的哪一类？分析层次与研究取向是否清晰？ | 开题即用"层次×取向"坐标锁定类型，按该类型的核心目标组织全文 | 文体错位：四类型混搭，既无理论建构又无问题解决 |
| 情境敏感性 | 结论能否在中国基层情境成立？西方理论是否经过情境化修正？ | 讨论制度约束、资源条件、执行环境；以理论为参照物而非裁判标准，从中国实践提炼话语 | 理论悬浮：移植硬套，文献综述一堆理论而正文分析与之无关 |
| 理论—经验对话 | 理论是否进入分析而非装饰？案例能否反过来修正理论？ | 构建逻辑清晰的分析指标体系，让理论与经验在正文中磨合 | 两张皮：理论只在综述出现，案例描述无概念产出 |
| 证据链完整 | 每个判断有没有来源？证据链是否可检验？ | 用问卷、访谈、案例等多元证据三角验证；注明时间、地点、主体与数据口径 | 素材堆砌：数据罗列无分析；观点先行再找例证 |
| 机制因果 | 变量间是相关还是因果？机制链条有无时序证据？ | 用过程追踪、互为因果分析揭示机制链条 | 相关当因果：以共现直接断言因果，罗列现象无机制 |
| 工具匹配 | 方法与工具是否与研究问题层次匹配？适用性风险是否评估？ | 按问题选工具，对技术方案做适用性与数据依赖批判 | 工具炫技：为用方法而用方法；宏观问题配微观工具 |
| 对策可行 | 每条建议是否对应一个已论证的问题？交给谁执行、靠什么激励？ | 问题与策略一一对应；对策含执行主体、工具与"监督—评估—整改—验收"闭环 | 对策空泛：喊口号式建议，无执行主体与验收环节 |
| 案例规范 | 案例来源与选择逻辑是否交代？案例的特殊性/普遍性位置是否明确？ | 说明案例选择标准与资料来源，用特殊性/普遍性连续谱定位案例价值 | 来源遗漏：不明资料出处；套模板丢分析主线 |
| 多元主体 | 除政府外，企业、社会组织、公民的角色与互动是否分析？ | 主体能力变化与主体间结构关系双线分析 | 单一政府视角：只见政府作为，不见多元主体互动 |
| 价值关怀 | 是否回应公共价值与公众利益？ | 讨论利益相关者与公共价值取向，区分技术效率与公共性 | 技术主义冷叙事：只谈指标不谈人 |
| 边界意识 | 证据、推断、建议是否分离？结论是否只到证据能支持的程度？ | 明确区分描述、关联、解释与因果推断；结论限定于证据范围 | 推断越界：由局部证据推出全局结论 |
| 规范意识 | 是否符合学术规范与 AIGC 披露要求？ | 守住原创边界与引用规范，按培养单位与期刊要求披露 AI 协助，不将 AI 生成的文字、数据或文献冒充本人成果 | 学术失范：引用失实、原创性声明不实 |
| 政策评估意识 | 政策效果评估是否区分产出与结果？是否考虑非预期后果？ | 使用逻辑模型（投入—活动—产出—结果—影响）评估政策效果；加入替代方案与反事实思考 | 只看投入不看效果：以经费投入和活动数量代替效果评估 |

## 课程—能力映射

课程名为 MPA 培养方案的通行主干课，不绑定任何具体学校；「支撑论文类型」对应论文四类型。

| MPA 核心课程 | 培养能力 | 支撑论文类型 | 论文落地点 |
|---|---|---|---|
| 公共管理学 | 政府组织与运作逻辑、理论定位与文献对话 | 专题研究、案例分析 | 治理机制分析框架、理论基础章节 |
| 公共政策分析 | 政策问题界定、工具选择与方案评估 | 公共政策分析、专题研究 | 政策评估维度设计、政策工具匹配与方案比照 |
| 公共经济学 | 公共资源配置、成本收益与财政逻辑 | 公共政策分析、专题研究 | 成本收益分析、预算约束与财政可行性论证 |
| 社会研究方法 | 问卷设计、抽样、统计与信效度论证 | 调研报告 | 方法章节设计、满意度测量与影响因素实证 |
| 定性研究方法 | 访谈、深描、过程追踪与机制识别 | 案例分析 | 案例选择逻辑、田野资料与理论磨合 |
| 公共部门人力资源管理 | 激励、考核与组织诊断 | 案例分析、专题研究 | 人事制度议题切入、组织机制分析 |
| 公共危机管理 | 应急机制与风险沟通 | 案例分析、公共政策分析 | 应急案例机制拆解、风险治理设计 |
| 电子政务与数字治理 | 技术应用、数据治理与数字风险批判 | 政策分析、专题研究 | 数字治理成效评估、技术治理结构分析 |
| 地方政府与基层治理 | 基层治理、央地关系与属地管理 | 案例分析、调研报告 | 基层实践切入视角、乡镇治理诊断 |
| 社会保障政策 | 需求评估、福利多元供给与服务质量测量 | 调研报告 | 公共服务供给与满意度实证 |
| 政府绩效管理 | 指标体系构建与闭环评估设计 | 调研报告、公共政策分析 | 评估指标体系、"监督—评估—整改—验收"闭环设计 |
| 学术规范与论文写作 | 文献综述、科学计量与学术诚信 | 全部四类型 | 文献综述章节、原创边界与 AI 协助披露自查 |

## 方法选择决策树

当数据和研究问题已明确但方法未指定时，按以下决策树选择：

```
数据+问题 ─┬─ 有明确处理组和对照组 + 前后时点 → 准实验（DID/事件研究）
           ├─ 有外生政策变化或自然断点 → RDD 或 自然实验
           ├─ 仅有截面数据 + 需要因果推断 → 工具变量或匹配法
           ├─ 大样本 + 高维特征 + 需要预测 → 机器学习辅助分析
           ├─ 小样本 + 深度理解需求 → 定性案例分析（过程追踪）
           ├─ 需要测量态度/满意度 → 问卷调查 + 统计建模
           ├─ 需要理解执行过程 → 半结构访谈 + 扎根理论
           └─ 需要评估政策效果 → 混合方法（定量测效果 + 定性解机制）
```

方法选择原则：方法服务于问题，不是问题迁就方法。报告所有方法的局限性和假设违反情况。
