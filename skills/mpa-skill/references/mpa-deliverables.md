# MPA Deliverables

Use the smallest artifact that answers the student's actual task. Every substantive artifact identifies which MPA Research Spine links are established, missing, or outside scope. Label evidence, inference, and recommendation separately.

| Deliverable | Required decision fields | Acceptance checks |
|---|---|---|
| course notes | source identity, page/section coverage, concepts, cases, instructor emphasis, questions, reusable assets | source-complete for the agreed corpus; notes link back to sources; no unverified note becomes thesis evidence |
| case analysis | focal public problem, actors, institutions, incentives, public value, implementation process, outcomes, alternatives | explains mechanisms rather than retelling events; compares plausible alternatives; identifies transfer limits |
| policy memo | decision maker, decision deadline, problem, options, evaluation criteria, trade-offs, feasibility, recommendation | recommendation follows from explicit criteria and evidence; implementation and risk are visible |
| literature map | applied question, concepts, theories, methods, findings, disagreements, evidence gaps | each claim traces to a verified source; gaps lead to a research need rather than decorative citations |
| proposal | applied problem, research question, scope, analytical framework, evidence, method, ethics, feasibility, contribution, risks | question is answerable; method fits the question; access and time constraints are credible |
| fieldwork | population or site, sampling, instrument, consent, data protection, collection protocol, quality checks | instrument maps to constructs; ethics and access are resolved before collection; deviations are logged |
| data analysis | raw-data inventory, quality audit, transformations, model or coding method, diagnostics, uncertainty, reproducible outputs | raw data is preserved; analysis is reproducible; association is not presented as causality without design support |
| thesis | chapter purpose, accepted evidence, argument chain, citations, limitations, applied contribution | prose follows evidence; citations are verified; conclusions stay within method and data limits |
| defence | audience, time limit, decision narrative, evidence figures, likely challenges, backup evidence | spoken story matches thesis evidence; slides remain legible; answers distinguish facts, inference, and judgement |

## Course-to-capstone reuse

Tag reusable concepts, cases, source cards, instruments, datasets, feedback, and analytic code with origin, date, course or project, source status, and permitted reuse. Before reuse in a proposal or thesis, return to the original source, verify the cited passage or data, and record the new decision context.
