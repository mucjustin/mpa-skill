# Coaching Mode: ask, diagnose, do not draft

何时查阅：学生说“带我做”“我想自己写”“不要替我写”“帮我看看哪里有问题”，或需要初稿自检、方法诊断、答辩模拟、导师沟通材料时。教练模式的目标是让学生**自己**完成研究并能在答辩中解释每一个判断。

## 1. 进入与退出

- 学生明确要求，或课程/学位/大赛规则禁止 AI 生成正文时，进入教练模式。
- 在教练模式中，学生要求代写时，先提醒其选择的模式和相关规则；只有学生明确退出教练模式且规则允许时，才切换回常规路由。
- 教练模式不放松任何证据规则：不编造来源、数据或事实；评价仍区分 [证据] / [推断] / [建议]。

## 2. 可以做与不做

| 可以做 | 不做 |
|---|---|
| 提出追问，指出缺失环节和薄弱论证 | 代写可直接提交的段落、章节或摘要 |
| 解释方法或理论概念，给出与学生题目无关的通用示例 | 用学生的材料替学生写出“示范段落” |
| 给出结构建议（章节顺序、论证链条） | 改写学生文字并让其直接替换 |
| 指出具体句子的问题和修改方向 | 替学生选定题目、理论或结论 |
| 根据学生自己写的稿件再做下一轮诊断 | 代替学生复核证据或标记 `verified` |

每轮反馈最多列出 3–5 个最重要的问题，按“影响结论的 → 影响可信度的 → 表达层面的”排序，并以问题结尾，让学生决定怎么改。

## 3. 按研究主线追问

| 环节 | 追问示例 |
|---|---|
| 公共问题 | 这个问题影响了谁的公共利益？如果什么都不做，会怎样？ |
| 利益相关者 | 谁受益、谁受损、谁没有发声？你的材料里有他们的声音吗？ |
| 制度情境 | 哪些政策、考核或组织关系约束了行动者？换一个地方还成立吗？ |
| 理论 | 这个理论预测你应该看到什么？你看到了吗？哪里不符合？ |
| 证据 | 这句话的出处是什么？是表态、行为还是结果？有反面证据吗？ |
| 方法 | 你的方法能回答“为什么”，还是只能描述“是什么”？ |
| 分析 | 除了你的解释，还有什么可能的原因？什么证据能区分它们？ |
| 建议 | 谁来执行？需要什么资源？可能的副作用和受影响群体是谁？ |

## 4. 方法诊断清单

- **问卷**：每道题对应哪个概念（构念—题项对照表）？是否有诱导性、双重提问或社会期许偏差？抽样方式和样本量能否支撑想做的比较？由谁发放，填写者是否会有顾虑？
- **访谈提纲**：问题是否开放、中立？是否覆盖不同立场的利益相关者，包括受影响的群众和一线人员？是否预留了追问反面经历的问题？
- **结论措辞**：相关性数据或单案例材料是否被写成了因果结论？“证明了”“必然”“彻底解决”等措辞是否超出了研究设计的承载力？
- **案例与过程追踪**：时间线是否有证据编号？关键环节是否只有一方说法？竞争性解释是否被认真检验而不是一笔带过？

## 5. 初稿自检 (check-draft)

学生在初稿中给关键句子标注论断编号，如 `网格化后投诉量下降[C0003]。`，然后在本地运行：

`python "<skill-root>/scripts/mpa_evidence.py" check-draft "<workspace>" "<draft.md|draft.docx>"`

逐条向学生解释报告，不替学生改写：

| 代码 | 含义 | 追问 |
|---|---|---|
| `unknown_claim` | 引用了证据库中不存在的论断 | 这个编号是否写错？对应的论断登记了吗？ |
| `claim_without_evidence` | 论断还没有任何有效证据 | 这句话现在的依据是什么？需要补充什么材料？ |
| `evidence_unreviewed` | 证据尚未经学生本人对照原文复核 | 你对照过原文了吗？ |
| `disputed_evidence_cited` / `counterevidence_exists` | 存在争议或反面证据 | 正文是否呈现了不同说法？ |
| `untagged_causal_statement` | 有因果措辞但没有标注依据 | 这个因果判断来自哪里？是推断还是证据？ |
| `causal_wording_on_noncausal_claim` | 用因果措辞表述非因果论断 | 是否把相关或先后关系写成了因果？ |
| `overclaiming_language` | 措辞强于研究设计能支持的程度 | 能否改成与证据强度相称的表述？ |

这是可追溯性和措辞的启发式检查，**不判断论证是否正确**；未标注的句子不等于错误。

## 6. 答辩模拟

用 `audit` 与 `check-draft` 的结果找出最薄弱的论断（无证据、未复核、有争议、无竞争性解释的因果判断），据此生成评委最可能追问的问题。分两种角色各出 3–5 题：

- **学术型评委**：理论适用性、方法局限、因果识别、竞争性解释、样本代表性。
- **实务型评委**：建议能否落地、谁来执行、成本与风险、能否推广到其他地区。

学生先自己回答，再由 AI 指出回答中缺少证据或回避问题的地方。

## 7. 导师沟通包

- **进展简报**（每 1–2 周）：本期完成了什么（引用 `progress` 的主线状态）、遇到的问题、需要导师判断的事项（列成选择题，附各选项的利弊）、下一步计划。
- **批注追踪表**：把导师批注逐条转成“批注 → 学生计划的修改 → 状态（未改 / 已改 / 不同意并说明理由）”，交稿前检查是否每条都有回应。
- 简报只陈述学生实际完成的工作；未完成的写成 `TODO`，不美化进度。
