# Routing

Choose the minimum sufficient route from capabilities actually available in the current Codex environment. Route coverage: course → case analysis → case competition entry → policy memo → literature → research design → fieldwork → data analysis → thesis → defence → non-MPA to MPA conversion. 路由覆盖：课程 → 案例分析 → 案例大赛 → 政策备忘录 → 文献综述 → 研究设计 → 田野调查 → 数据分析 → 学位论文 → 论文答辩 → 非公管转公管。

| Route | Intended output | 中文关键词 | Sequence rule |
|---|---|---|---|
| course | notes, revision map, assignment inputs | 课程复习、笔记整理、作业辅导 | inventory and read the agreed corpus before synthesis |
| case analysis | applied case brief | 案例分析、案例简报、案例报告 | establish actors, institutions, mechanisms, outcomes, and alternatives before lessons |
| case competition entry | competition-grade entry plan | 案例大赛、竞赛参赛、案例竞赛 | read [case competition rules](mpa-case-competition.md), verify the current-year notice, and confirm fieldwork evidence and theory applicability before drafting |
| policy memo | decision-ready memo | 政策备忘录、政策建议、政策咨询 | define audience and options before recommendation |
| literature | source set, source cards, literature map | 文献综述、文献检索、文献地图、文献卡片 | tie search and reading to the applied question; verify identity before citation |
| research design | proposal or design memo | 研究设计、研究方案、开题报告 | define problem, question, scope, framework, evidence, and method before prose |
| fieldwork | sampling and collection package | 田野调查、实地调研、问卷设计、访谈 | resolve ethics, access, instrument mapping, and data protection before collection |
| data analysis | reproducible analysis and report | 数据分析、定量分析、统计建模、数据处理 | audit data quality and preserve raw data before transformation or modelling |
| thesis | evidence-grounded chapters | 学位论文、毕业论文、硕士论文、论文写作 | accept evidence and analysis before drafting or polishing |
| defence | presentation and challenge preparation | 论文答辩、答辩准备、答辩演示 | stabilize thesis claims before narrative and visual production |
| non-MPA to MPA conversion | re-anchored MPA research design | 非公管转公管、跨学科转MPA、方向转换 | audit source-data consistency and remap the public problem, stakeholders, and theory through the MPA Research Spine before rewriting; when the user supplies raw data, run the data route before drafting; rewording alone is not conversion |
| theory grounding | theory-map reference | 理论选择、理论定位、分析框架、理论依据 | select theory before evidence design; confirm paper-type fit |
| china-context check | china-contexts reference | 中国情境、适用性检验、治理语境、本土化 | verify governance context and constraints before conclusion |

For cross-route work, order only the needed phases by dependency. A common sequence is intake → theory grounding → course/case assets → literature → research design → fieldwork → data → thinking check → thesis → defence. Theory grounding reads [theory map](mpa-theory-map.md) before evidence design; thinking check runs [thinking checklist](mpa-thinking-checklist.md) before prose acceptance.

For conversion and data-bearing thesis work, use: capability/access preflight → source, data, and numerical consistency audit → real-data analysis or explicit evidence gap → content → language/visuals → document delivery → optional integration → acceptance. When claims depend on supplied data, read [real-data workflow](real-data-workflow.md) before content. Read [local Office editing](local-office-editing.md) only after content acceptance and only when an available local Office capability is required.

Offer Zotero or Obsidian integration once in the route confirmation when a substantive research task states no preference; write nothing to either before the user confirms.

For case competition entries, plan the three-document structure (案例正文, 案例分析报告, 调研报告), fieldwork evidence, and theory applicability before any drafting; course case-analysis assignments use the research contract without competition deliverables.

Use [MPA deliverables](mpa-deliverables.md) to shape the output and [MPA research contract](mpa-research-contract.md) to gate claims. Read [case competition rules](mpa-case-competition.md) before case-competition entry planning. Read [dependencies](dependencies.md) before selecting specialist tools. Read [real-data workflow](real-data-workflow.md) before rerunning analysis on user-supplied data. Read [local office editing](local-office-editing.md) only after content acceptance and only when the route requires local Office mutation and a corresponding capability is available. Read [theory map](mpa-theory-map.md) before research design or thesis drafting; read [china contexts](mpa-china-contexts.md) before case analysis or policy recommendations; read [thinking checklist](mpa-thinking-checklist.md) before each draft acceptance; read [course map](mpa-course-map.md) before course assignments or study planning. Do not invoke this controller merely because a request mentions a thesis, spreadsheet, Zotero, Obsidian, teaching, or writing without MPA context.
