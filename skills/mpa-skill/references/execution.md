# Execution Handbook

何时查阅：涉及数据重分析、本地文档写入、依赖工具选择或工作区配置时读取。Merges data workflow, Office editing, dependency management, and workspace configuration.

## 数据工作流 (Data Workflow)

有原始或项目数据时适用。结论跟数据走，不是数据跟结论走。Preserve raw data untouched; conclusions follow the data, never the reverse.

### 操作顺序

1. 审计数据质量，保留原始文件不动；记录纳入和排除规则及计数。
2. 重跑分析后再动正文。Mark 无法支持的数据声明为 `AUTHOR_INPUT_NEEDED`；不捏造数值、样本量或拟合统计量。
3. 改写受影响的结论，然后双向验证每个数值回写：新值存在、旧值消失。

### 方法纪律

- 标准化分数描述参考系内的相对位置。Z 分数按考试场次计算时，每场均值归零，组中心编码相对位置而非绝对进步。增值或改进声明必须指明支撑它的参考系。
- 纵向追踪：一次性对所有观测拟合降维和聚类（全局 PCA、全局 KMeans），再分配标签。按场次分别拟合导致组边界漂移、追踪断裂。
- 分类器准确率须与多数类基线和混淆矩阵一并报告；不平衡目标上的高准确率不等于可用召回率。
- 每个报告指标旁标注验证设计（划分比例、分层、随机种子）。

### 图表纪律

- 不发明数据点。图表只渲染计算输出。
- 密集轨迹：标记首末点而非每个点，加方向提示。
- 交付前检查图例和坐标轴标签是否重叠。
- CJK 字体合约：在绘图脚本的 `font.sans-serif` 中先放 CJK 字体；不依赖全局 matplotlibrc。

### 数值回写纪律

- 每个数字保持单一真值源（分析输出 JSON 或等价物），正文和表格从中派生。
- 替换整段或整表单元格；不在句子内部修补数字。
- 所有替换报告成功后才保存；重新定位失败项并重跑。

## 本地 Office 编辑

仅在内容已验收、路线需要本地 Office 变更且相应能力实际可用时加载。

### 能力预检

列出现有工具并检查其 schema。名称仅为提示，返回结构才是契约。从当前状态记录文档身份、版本和保存目标。调用前确认工具存在：先 list，再 schema。建表用 `doc_insert_table_by_csv` 或全区域 `doc_modify_table_region`；不存在 `doc_insert_table`。

### 变更事务

1. 捕获结构或版本快照。
2. 从文档中找到活动锚点并要求唯一匹配。
3. 严格按文档降序应用位置编辑。
4. 每批后验证工具实际返回的字段并探测结果内容。

### 调用纪律

- 字符串参数走 `--json`。`key=value` 形式的值会先按 JSON 解析，查找文本如 `0.571` 会静默变成数字导致调用失败。
- 图片内容带 `file://` 前缀用于替换，或用绝对本地路径插入；不带 `data:` 前缀的裸 base64 会被拒绝。
- 按每个工具的实际返回形态判断成功：表区域编辑返回 `update_count` 和 `version`，图片插入返回 `image_url`。不假设共享 `message` 字段。
- 同结构单元格文本更新：用 `inherit_styles: true` 部分修补，仅传变更单元格。
- 结构变化（行数或列数变化、合并）：全区域单元格载荷；服务端删除并重建表格。
- 在占位段落开头插入图片，然后删除占位文本并保留标题。宽度约 550 px（96 DPI）适合正文；高度从宽高比计算。

### 中断恢复

中断或身份漂移后，重开文档并重新获取标识符。编辑服务可能在运行中停止，`file_id` 等易失句柄重开后会变化。恢复 SOP：

1. 通过预览入口点重开文档。
2. 从编辑器池状态获取新的 `file_id`；不复用缓存句柄。
3. 探测一个旧文本和一个新文本，判断早期写入是否落地；未触碰文件报告 `is_dirty: false`。
4. 将变更状态分类为：未应用、已应用、部分应用或 `STATE_UNKNOWN`。
5. 对已知状态用幂等操作恢复。降序使重跑安全。
6. 遇 `STATE_UNKNOWN` 立即停止。绝不从未知状态继续变更或宣称成功。

### 验收

验证新内容存在、旧内容消失、保存的产物可重开或渲染、目标与返回的版本/更新证据一致。报告计数。

## 依赖管理

所有集成为可选项 (all integrations are optional)。编排路线前先检查已安装的 Skills、插件、应用和工具；不从名称推断集成存在。

| 需求 | 已安装时的首选能力 | 优雅降级 |
|---|---|---|
| 文档和 PDF | 已安装的文档/PDF 阅读器和转换器 | 直接读取支持的文件；报告不支持的格式 |
| 文献工作流 | 端到端文献控制器 | 分别使用验证过的检索、合法获取和源卡片能力 |
| 单篇论文阅读 | 论文卡片或全文阅读器 | 提取基于源的结构化阅读笔记 |
| 研究设计 | 学术研究或提案工作流 | 直接应用 MPA 研究契约 |
| 定量或定性数据 | 已安装的分析、表格、笔记本或统计工具 | 审计数据并报告缺失的执行能力 |
| 引用 | 引用和参考文献验证工具 | 使用可用的权威来源验证标识符和字段 |
| Zotero | 支持的本地 API、连接器或链接附件助手 | 准备验证过的用户运行交接；绝不直接编辑数据库 |
| Obsidian | 本地 Markdown 文件系统访问或 Obsidian 集成 | 授权时将可移植 Markdown 写入配置的 Vault |
| Word 或幻灯片 | 已安装的文档或演示文稿工作流 | 交付已验收的 Markdown 和交接规范 |

当首选依赖不可用时，选择保持所需证据和安全边界的最接近已验证能力。若无适当能力，执行前报告缺失依赖，将已完成的只读分析与被阻塞的集成分开。

### 已验证的集成陷阱

| 领域 | 已验证行为 | 规则 |
|---|---|---|
| 本地编辑器参数 | `key=value` 先按 JSON 解析值 | 字符串参数走 `--json` |
| 本地编辑器图片 | 不带 `data:` 前缀的裸 base64 被拒绝 | 用 `file://` 前缀本地路径 |
| 本地编辑器会话 | 服务可能运行中停止且 `file_id` 重开后变化 | 重读池状态、探测写入状态、幂等重跑 |
| 本地编辑器表格 | `doc_insert_table` 不存在；区域编辑返回 `update_count` 而非 `message` | 用 `doc_insert_table_by_csv` 或全区域 `doc_modify_table_region`；按返回形态判断成功 |
| Zotero 本地 API | 已验证配置中为只读（写入返回 501） | 通过连接器 API 写入；为剩余部分准备手动交接 |

## 工作区配置

首次持久写入前解析本地路径。绝不推断示例路径存在。

### 解析顺序

1. 设置了 `MPA_WORKSPACE_CONFIG` 环境变量时读取其命名的 JSON 文件。
2. 否则 Windows 上读取 `%APPDATA%\mpa-skill\config.json`。
3. 无有效配置时，运行 `scripts/Initialize-MpaWorkspace.ps1` 或请用户选择工作区根目录。

必需 JSON 属性：`workspace_root`、`obsidian_vault`、`zotero_executable`、`zotero_attachments`、`research_data`、`research_projects`。配置是本地机器状态，不提交到 Skill 仓库。

### Zotero

绝不直接修改 `zotero.sqlite`。使用支持的本地接口，验证重复和父项决策，优先使用合法的已有附件，验证最终附件路径。工作流确认后，若路线需要 Zotero 且其支持的本地接口不可达，自动启动配置的 Zotero 可执行文件，等待就绪后继续。仅在自动启动失败时请用户手动启动。

### Obsidian 和文件

每个源保持一个规范源笔记，将派生的课程、案例、提案或论文笔记链接到它。记录源身份、页面证据、访问日期、集成状态、决策、待办和风险。保留原始数据并与清洗数据、代码、表格、图表和报告分离。
