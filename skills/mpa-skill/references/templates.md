# MPA Templates

实用模板库：每种路由的落地骨架。模板是起点不是终点——根据研究问题调整结构，用 `mpa-research-contract.md` 校验质量，用 `mpa-knowledge.md` 校验理论。

## 答辩准备模板 (Defence Preparation Template)

```
# 答辩准备

## 一、陈述要点（按时间线）
| 时间段 | 内容 | 关键信息 | 支撑材料 |
|---|---|---|---|
| 0-2min | 研究问题与意义 | 一句话说清问题 | |
| 2-5min | 文献与理论 | 研究缺口 + 理论选择 | |
| 5-8min | 研究设计 | 方法 + 数据 | |
| 8-10min | 主要发现 | 3 个核心发现 | 图表 |
| 10-12min | 结论与贡献 | 理论 + 实践 + 边界 | |
| 12-15min | 预留弹性 | | |

## 二、预判问题
| 可能问题 | 回答要点 | 证据位置 |
|---|---|---|

## 三、底线备份
- 方法质疑 → 备用分析结果
- 数据质疑 → 数据来源证明
- 理论质疑 → 替代理论分析

## 四、视觉检查清单
- [ ] 字号最后排可见
- [ ] 图表有标题和数据来源
- [ ] 每页不超过一个核心信息
- [ ] 颜色对比度足够
```
