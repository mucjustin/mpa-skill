# MPA Course Map

何时查阅：课程作业、培养规划、选题定位时读取，把 MPA 核心课程培养的能力映射到论文类型与论文落地点；与 `mpa-deliverables.md` 的交付物规格互指。课程名为 MPA 培养方案的通行主干课，不绑定任何具体学校；「支撑论文类型」对应 MPA 论文四类型（专题研究、案例分析、调研报告、公共政策分析）。

| MPA 核心课程 | 培养能力 | 支撑论文类型 | 论文落地点 |
|---|---|---|---|
| 公共管理学 | 政府组织与运作逻辑、理论定位与文献对话 | 专题研究、案例分析 | 治理机制分析框架、理论基础章节 |
| 公共政策分析 | 政策问题界定、工具选择与方案评估 | 公共政策分析、专题研究 | 政策评估维度设计、政策工具匹配与方案比照 |
| 公共经济学 | 公共资源配置、成本收益与财政逻辑 | 公共政策分析、专题研究 | 成本收益分析、预算约束与财政可行性论证 |
| 社会研究方法 | 问卷设计、抽样、统计与信效度论证 | 调研报告 | 方法章节设计、满意度测量与影响因素实证 |
| 定性研究方法 | 访谈、深描、过程追踪与机制识别 | 案例分析 | 案例选择逻辑、田野资料与理论磨合 |
| 公共部门人力资源管理 | 激励、考核与组织诊断 | 案例分析、专题研究 | 人事制度议题切入、组织机制分析 |
| 公共危机管理 | 应急机制与风险沟通 | 案例分析、公共政策分析 | 应急案例机制拆解、风险治理设计 |
| 电子政务与数字治理 | 技术应用、数据治理与数字风险批判 | 政策分析、专题研究 | 数字治理成效评估、技术治理结构分析 |
| 地方政府与基层治理 | 基层治理、央地关系与属地管理 | 案例分析、调研报告 | 基层实践切入视角、乡镇治理诊断 |
| 社会保障政策 | 需求评估、福利多元供给与服务质量测量 | 调研报告 | 公共服务供给与满意度实证 |
| 政府绩效管理 | 指标体系构建与闭环评估设计 | 调研报告、公共政策分析 | 评估指标体系、"监督—评估—整改—验收"闭环设计 |
| 学术规范与论文写作 | 文献综述、科学计量与学术诚信 | 全部四类型 | 文献综述章节、原创边界与 AI 协助披露自查 |
