# MPA Research Agent v2.2.1

**「证据之河」品牌标识更新 / Evidence River Visual Identity**

本版本为 v2.2.0 的视觉补丁，不改变研究功能、数据结构与安装标识。

## 变化

- 重设计 [主图标](https://github.com/mucjustin/mpa-skill/blob/v2.2.1/assets/logo.svg)：证据流贯穿公共治理与知识体系，保留公共管理研究的专业属性，取消通用「勾选成功」图形。
- 同步更新 [项目横幅](https://github.com/mucjustin/mpa-skill/blob/v2.2.1/assets/banner.svg)，新增适用于文档及单色制作的 [logo-mono.svg](https://github.com/mucjustin/mpa-skill/blob/v2.2.1/assets/logo-mono.svg)。
- 增加 [品牌说明](https://github.com/mucjustin/mpa-skill/blob/v2.2.1/docs/brand-identity.md)，明确小尺寸、配色、研究核验概念的使用边界。
- 原 GitHub 地址 `mucjustin/mpa-skill`、Skill ID `mpa-skill`、Python/SQLite 核心及 WorkBuddy ZIP 分发方式保持不变。

## 下载

- `mpa-skill.zip`：完整单 Skill 安装包。
- `SHA256SUMS`：安装包 SHA-256 完整性校验。
- Codex 可使用 `npx skills add mucjustin/mpa-skill -g -s mpa-skill -y --full-depth` 安装主分支最新版。

现有 SQLite 证据工具仍**不加密**；逐字匹配不代表真实研究结论得到了核验。WorkBuddy GUI 实际导入和真实学术效果 A/B 验证仍未开展。本次 CI 仅验证软件行为、SVG 结构及文档引用。

既有功能变更和限制详见 [v2.2.0](https://github.com/mucjustin/mpa-skill/releases/tag/v2.2.0)。
