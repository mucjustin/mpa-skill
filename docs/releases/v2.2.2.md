## 下载与验证

- **`mpa-skill.zip`**：单 Skill 安装包，可用于 Codex 和符合导入格式的 WorkBuddy 等客户端。
- **`SHA256SUMS`**：安装 ZIP 的 SHA-256 完整性校验文件。
- Codex 更新：`npx skills add mucjustin/mpa-skill -g -s mpa-skill -y --full-depth`。

本次 CI 检查包括 Python/SQLite 核心行为测试、独立 Skill 包可运行性、SVG XML 与字母路径结构、文档链接和版本一致性。**没有宣称 WorkBuddy 客户端 GUI 已完成验证，也没有新增学术效果实验。** 已保存的本地证据库仍无静态加密，研究者需自行负责授权和保护。
