# MPA Research Agent v2.2.0

**公共管理证据研究助手 · Evidence-Grounded Research Agent Skill**

本版把 [Case Research Engine PR #2](https://github.com/mucjustin/mpa-skill/pull/2) 和 [离线证据工作台 PR #3](https://github.com/mucjustin/mpa-skill/pull/3) 合并为一个可安装的 Skill。

## 主要新特性

- 案例研究：视角选择、动态利益主体、证据规划、事件追踪、机制和替代解释、研究结论边界。
- 离线 Python/SQLite 证据工作台：TXT/Markdown、UTF-8 CSV、DOCX 和可提取文本的 PDF（可选 `pypdf`）；包含原文件 SHA-256、原文定位、主张—引文关联、人工审核、审计以及 Markdown/JSON 导出。
- 便携安装：Codex Skill 原目录直接携带 Python 工具，WorkBuddy 导入候选 ZIP，双语元数据、`doctor` 环境检查、隔离安装测试。
- 项目品牌：MPA Research Agent，新标识、Research Spine/执行流程/证据架构图和中英文安装文档。

## 下载与校验

- **`mpa-skill.zip`**：只包含单个 `mpa-skill/` 目录，适用于支持导入 Skill ZIP 的客户端。
- **`SHA256SUMS`**：包含 ZIP 的 SHA-256 摘要，便于核对下载完整性。
- Codex 获取主分支最新代码：`npx skills add mucjustin/mpa-skill -g -s mpa-skill -y --full-depth`。
- 需要重现特定版本时，请使用本 Release 附件或对应 Git 标签，不要把持续变化的 `main` 当作固定版本。

## 限制与已知风险

- Python 功能、ZIP 解压隔离执行和研究规则契约经过 CI；**WorkBuddy 客户端 GUI 实际导入尚未独立测试**。
- SQLite 和原文快照保存在用户指定的本地工作区，**未加密**；处理学生、访谈、单位资料需事先符合授权与安全要求。
- 来源 SHA-256、逐字引用和人工 `verified` 仅代表来源一致性/研究者标记，不证明研究主张真实、独立或因果成立。
- 尚未完成真实研究任务下的 A/B 质量改进验证，不能以程序测试代替学术效果评估。
