# MPA Research Agent v2.3.1 — Evidence and Skill Compatibility Fixes

**公共管理证据研究助手 · 证据核验与通用格式修复**

## 修复

- 已授权的只读分析直接执行；Zotero/Obsidian 仅按请求或既有授权使用。外部写入、来源持久化及人工复核继续受授权范围约束。
- 新增文献库证据就绪规则：核对目录分表、重复别名、阅读范围、方法标签与原文冲突；区分方法文献和实际项目数据。
- Research Spine 按任务用于诊断相关缺口，并随证据调整问题与方法。
- 纵向预测按训练／评价划分拟合预处理，避免未来数据泄露；描述性全样本分析不冒充样本外评价。
- 文档编辑使用当前工具 schema 与实际返回；未知写入状态先停止并核验，避免盲目重放。理论地图明确不能直接用作引文证据。
- 通用 Skill 格式修复：自定义字段移入标准 `metadata` 字符串，版本检查读取 `metadata.version`。双语展示信息、作者和示例保留。

## 兼容与安装包

- `mpa-skill.zip`：单个可安装的 `mpa-skill/` 目录；`SHA256SUMS`：安装包 SHA-256 校验值。
- 本次不改 Python CLI、SQLite 数据库结构或现有证据记录，无需数据迁移。
- 自行读取旧顶层 `version` 等字段的外部工具需改读 `metadata.version` 等字段。Codex 界面配置仍在 `agents/openai.yaml`。

## 验证与边界

- 55 个项目测试、源码及解包后安装包的通用 Skill 校验、发行元数据检查通过；跨平台 CI 覆盖 macOS / Windows / Ubuntu 与 Python 3.10 / 3.13。
- 四个独立合成开发案例在两轮试跑中均通过预设标准；完整回答与限制保存在 `docs/validation/`。这些单次试跑不构成一般可靠性估计。
- 未独立验证 WorkBuddy GUI 实际导入或真实学生使用效果。程序校验不证明研究结论正确，模型不能自行将证据标记为人工 `verified`。
- 本地 SQLite 与来源快照仍未加密；自动脱敏不能替代分享前的人工检查。
