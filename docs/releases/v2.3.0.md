# MPA Research Agent v2.3.0 — In-Service Students, Coaching and Cross-Platform

**公共管理证据研究助手 · 面向在职 MPA 学生的版本**

本版围绕在职 MPA 学生的实际处境（研究本单位问题、材料敏感、时间零碎、需要真正学会研究）扩展 Skill，并移除 PowerShell 依赖，使 macOS、Windows、Linux 用户只需 Python 3.10+ 即可使用全部本地工具。

## 主要新特性

- **在职研究指南**（`references/in-service-research.md`）：工作问题 → 选题四层拆解与候选题比较；局内人研究检查（角色冲突、权力关系、知情同意、材料分级、沉默群体）；论文与政策建议报告同源产出。
- **教练模式**（`references/coaching-mode.md`）：只追问与诊断、不代写；按研究主线追问、方法诊断清单、答辩模拟、导师沟通包。
- **证据工作台新命令**：`check-draft`（初稿论断—证据覆盖、未标注因果措辞、过度断言）、`progress`（研究主线状态与待办续接）、`redact` 与 `export --redact-terms`（本地脱敏）、`workspace-init` / `env-check`（跨平台工作区配置）。
- **更可用的引文定位**：跨行/跨页范围定位（如 `L3-L5`）；显式 `--normalized` 匹配可容忍 PDF 抽取产生的空格、换行与全半角差异，但仍只保存原文逐字片段；DOCX 脚注（`fn.N`）和尾注（`en.N`）。
- **竞争性解释**：`claim --rival-of` 登记竞争性解释；审计提示没有竞争性解释的因果论断和没有证据的竞争性解释。
- **中文触发**：标准 `description` 字段加入中文关键词，中文请求更容易触发本 Skill。

## 移除与迁移

- 删除 `Initialize-MpaWorkspace.ps1`、`Test-MpaEnvironment.ps1` 及全部 PowerShell 测试；由 Python 子命令和测试替代。原配置文件格式不变，Windows 默认路径不变。
- 删除与 Skill 无关的 `ml-analysis/` 旧实验代码。
- 证据库结构升级到版本 2；打开 v2.2.x 工作区时自动原地迁移，已有证据、复核状态和快照保持不变。

## 下载与校验

- **`mpa-skill.zip`**：单个 `mpa-skill/` 目录，适用于 Codex 和 WorkBuddy ZIP 导入。
- **`SHA256SUMS`**：ZIP 的 SHA-256 摘要。
- 证据工具使用 Python 标准库与 SQLite；PDF 文本提取仍需单独授权安装可选 `pypdf`。

## 限制与已知风险

- 新功能通过合成数据的单元与 CLI 测试，CI 覆盖 macOS / Windows / Linux；**尚未经过真实在职学生的使用评估**，WorkBuddy GUI 实际导入仍未独立测试。
- 脱敏自动规则只是兜底；人名、单位、地名必须由学生列入术语表并在分享前人工通读。
- `check-draft` 是可追溯性与措辞的启发式检查，不判断论证是否正确；`--normalized` 匹配须由研究者核对语境。
- 本地 SQLite 与快照仍**未加密**。
