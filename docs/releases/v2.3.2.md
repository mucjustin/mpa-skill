# MPA Research Agent v2.3.2 — Evidence Gates and Recoverable Errors

**公共管理证据研究助手 · 证据门禁与可执行的错误提示**

## 新增

- `audit --strict`：未决警告（待复核、论断无证据、因果论断无竞争解释）同样令 `ok` 为假并返回退出码 2。默认严格度不变，只有完整性错误才拦；需要「干净交付」或写脚本、写自动化门禁时加 `--strict`。`audit` 输出同时新增 `counts`（error/warning/info）与 `strict` 字段，不必再自己解析 `issues`。
- `doctor` 新增 `python_minimum`、`python_usable`、`python_status`、`warnings`：把「受测下限（3.10）」与「本机能否实际跑完所有命令」分开报告。低于下限但可运行的解译器会得到 `python_supported: false` 加一条明确警告，而不是一个无法解释的布尔值。
- 新增[十分钟快速开始](../quickstart.md)：一份材料从预检、导入、定位、立论、引证、人工复核、门禁审计到导出的完整路径，含失败信息对照表与命令一览。

## 修复

- `cite` 的失败信息改为可执行：引文在别的段落时指出它实际所在的定位；引文近似时给出最长逐字片段与多余字符；完全不匹配时给出可直接粘贴的 `segments` 检查命令。逐字匹配规则未被放松，`--normalized` 仍只处理空白与全半角差异，并保存原文逐字片段。
- 「未知文档 ID」错误列出已登记文档及 `ingest` 提示。文档 ID 由内容哈希派生，无法靠格式猜测，之前只回一句 `Unknown document ID.`。
- `tests/test_skill_portability.py` 不再假定运行环境一定是受支持解释器：`python_supported` 的期望值由 `sys.version_info` 推导，并断言 `python_usable` 与 `warnings` 一致。

## 兼容与安装包

- `mpa-skill.zip`：单个可安装的 `mpa-skill/` 目录；`SHA256SUMS`：安装包 SHA-256 校验值。
- 版本双轴对齐：`pyproject.toml` 版本与 Skill 版本统一为 2.3.2，`tools/check_release.py` 交叉校验；此前该文件停留在 `0.1.0` 且 CI 无法发现。
- 不改 Python CLI 参数、SQLite 数据库结构或现有证据记录，无需数据迁移。旧工作区可直接继续使用。
- 删除 `.github/workflows/release-recovery.yml`：它是 v2.3.1 发布补救用的一次性工作流，版本写死在该发行上，保留只会在手动触发时失败。正常发行仍由 `ci.yml` 的 `publish-release` 承担。

## 验证与边界

- 69 个项目测试在本地 Python 3.9.6 下全部通过（新增 `tests/test_diagnostics.py` 12 例、发行元数据 2 例）；发行元数据检查与打包检查通过；解包后的 `mpa-skill.zip` 在独立目录中复核了 `audit --strict` 的退出码与 `doctor` 字段。跨平台 CI 覆盖 macOS / Windows / Ubuntu 与 Python 3.10 / 3.13。
- 测试通过只说明规则与结构成立，不证明研究结论正确。程序校验不证明材料真实、观点代表性或因果机制；`verified` 只能由研究者对照原文后声明，模型不得自查自批。
- 本地 SQLite 与来源快照仍未加密；自动脱敏不能替代分享前的人工检查。WorkBuddy GUI 实际导入仍未离线验证。
