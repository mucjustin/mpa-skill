# 品牌标识 / Visual identity

**MPA Research Agent · 公共管理证据研究助手**

本次视觉标识用“证据之河”取代传统的“书本 + 对勾”组合。核心构型为三层关联：下方打开的知识源、中间贯通的研究/证据路径、上方公共治理实践的抽象城市轮廓。两侧节点象征不同利益主体和多来源证据。它表达的是**从证据到公共价值的研究路径**，而不是 AI 自动认证研究结论。

## 图形文件

- [主图标](../assets/logo.svg)：512 × 512，深色圆角方形背景，可用于 GitHub 头像和 Skill 资料。
- [单色版本](../assets/logo-mono.svg)：256 × 256，基于 `currentColor`，用于文档、水印及丝网印刷。
- [项目横幅](../assets/banner.svg)：1280 × 405，采用一致的证据之河、知识源和公共治理视觉语汇。

## 使用建议

- 项目头像与小图优先使用主图标，不要在其内部叠加英文全称或勾选符号；图标设计按 32、64、128、512 像素检查识别效果。
- 对于需要大面积显示的 README 或介绍页面使用 Banner；论文封面或报告使用单色 SVG，并明确设置 `color`（如 `#132C45`）。
- 建议配色：深海军蓝 `#102C47`、河流青绿 `#35AEA8`、纸张象牙白 `#FFF9E9`、金色证据节点 `#F0C581`。
- SVG 不引用任何外部网络资源、远程字体或位图。所有图形独立于 WorkBuddy/Codex 客户端。
- **避免把品牌图标解释为证据已核验的勾选标记**；真正的来源校验和人工复核状态以产品自身工作流记录为准。

注意：替换 GitHub 仓库的 `assets/logo.svg` 只会改变 README 内展示的标识，**不会自动修改 GitHub 账户头像或仓库社交分享预览图**。后两者需要通过 GitHub 页面对应设置分别更换。
