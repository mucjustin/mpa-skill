# 品牌标识 / Visual Identity

**MPA Research Agent｜公共管理证据研究助手**

## 核心标识：MPA 字母图形（2026-10-26）

新版将抽象的「证据之河」改为能够直接读出 **MPA** 的一体化字母标志，参考上一轮三个概念方案中最简洁的字母构图。采用不依赖字体的 SVG 路径绘制 M、P、A，强调识别性，而不是将书、地球、政府大楼、勾选或 AI 芯片等素材叠加到图标中。

- **M**：清晰的粗体字母，内部三根递增的青绿色数据柱，代表证据积累与数据分析。
- **P**：完整的几何字母，承接 Public / Policy，保证 MPA 缩略语可读。
- **A**：向上延伸的青绿色弧线，代表从分析走向可执行的公共价值与研究进展；并不表示「事实已验证」。
- **设计原则**：符号先于解释、少元素、高对比、缩小仍可读；避免过度抽象或把复杂流程图放进产品 Logo。

## 规范

- 主色：深海军蓝 `#0D2F52`；数据柱：研究青绿 `#0EA99C`；上升弧：浅青绿 `#1FBDC0`；背景：`#F9FBFC`。
- 小尺寸（32 / 64 px）只能用主图标，不要再加中文副标题或“Research Agent”等字样，避免字形拥挤。
- SVG 主标志为几何路径，不依赖外部字体、网络请求或第三方素材；横幅的文本标签使用系统字体回退。
- 尊重 GitHub、Codex 与 WorkBuddy 客户端实际裁切形式；本次只变更仓库资产，**GitHub 个人头像或仓库 Social Preview 必须在 GitHub 设置中另外调整**。
- 用户看到的字母 MPA 是品牌缩略语，不是证据已核实的系统标记。技术工具的来源校验与人工复核规则保持不变。
