**原流程不适合评价样本外预测。**即使标准化、PCA 和 KMeans 不使用人工标签，在全部五年数据上拟合，也会让第4—5年的分布信息进入训练流程，造成未来信息泄露。跨期类别一致，应通过**冻结训练期的转换参数和聚类中心**实现。

建议按以下步骤调整：

1. **先明确预测时点和目标。**区分“用当年信息识别当年类别”与“用过去信息预测下一年类别”。如果分类器输入与生成聚类标签的变量来自同一年，准确率主要反映对聚类规则的复现，不能直接解释为提前预测能力。若要提前预警，输入只能包含预测时点已经可获得的信息。

2. **核对纵向数据的可比性。**检查五年的变量定义、量表、考试难度、缺失情况及学生追踪关系，保留原始数据。若成绩分别按每年标准化，所得分数表示年内相对位置，不能据此认定学生取得了绝对进步；统一转换也不能自动消除测量口径差异。

3. **先划分时间，再拟合处理流程。**第1—3年作为开发数据，第4—5年作为留出评价数据。缺失值填补、标准化、PCA、KMeans及特征筛选，均只在训练数据上拟合。评价数据只使用已冻结的参数进行转换，再按最近的训练期聚类中心分配类别，不重新拟合。

4. **只在开发期调参。**采用按时间向前推进的验证，例如较早年份训练、较晚年份验证；每个验证折都重新在该折训练部分拟合完整流程。PCA维数、聚类数和分类器参数不能根据第4—5年的表现选择。若预测未来类别，训练样本的目标年份也必须在开发期内：例如用第2年信息预测第3年类别；不能把第4年标签用于训练。

5. **固定最终方案后评价第4—5年。**如目标是在第3年末一次预测未来两年，两年的输入都须限于当时已知信息；如采用逐年更新的一步预测，应另行说明更新规则。两种设计对应不同任务，不能混报。

6. **同时报告表现与局限。**分别报告第4年、第5年的准确率、混淆矩阵、各类召回率及宏平均F1，并与训练期确定的多数类基线比较；未来类别预测还可加入“维持上一期类别”的基线。同一学生跨年出现，符合追踪既有学生的任务，但不能据此宣称适用于新学生；不确定性估计应考虑学生内重复观测。检查类别占比、到聚类中心的距离等漂移情况，冻结类别并不保证其教育含义始终稳定。

在MPA教育公共服务研究中，还需判断漏识别需要支持的学生、错误预警及群体间误差的实际后果。聚类类别属于操作性分类，预测表现不能直接证明教育服务或政策产生了因果效果。

**当前只能给出方法判断和分析方案；尚未运行，不能报告实际准确率或断言模型有效。**若另做五年全样本聚类，可将其定位为描述性分析，与上述预测评价分别报告。
