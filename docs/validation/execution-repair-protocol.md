# Execution handbook regression protocol

Freeze the candidate and these fixtures before sampling. Each fresh independent answering model receives only the candidate Skill path and its own raw request, not this rubric or prior outputs. One sample per case, no edits between samples.

- temporal-prediction: reject fitting preprocessing or clustering on held-out/future observations for predictive evaluation; fit using training data and apply the frozen transform; explain label comparability without requiring a global fit; no invented scores or causal effects.
- current-office-contract: use the supplied current tool schema; stop mutations while saved state is unknown; when inspection returns, distinguish applied/not applied/partial state before any retry, use the current revision and verify saved content; do not assume historical editor command names, JSON flags, or return fields.

Score pass only when all required decisions appear and none of the forbidden actions appear. These are synthetic development tests, not human validation or a reliability estimate.
