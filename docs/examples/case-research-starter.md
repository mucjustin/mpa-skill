# Evidence-led case research: starter walkthrough

This is a **hypothetical learning example** about implementing a school academic early-warning policy. It does not describe a real school, student, interview or policy result.

## User request

"某高中实施学业预警后，不同班级执行差异明显。请帮我设计一个可调查的公共管理案例研究问题。现在只有制度文件，尚无访谈和执行台账。"

## Expected route (illustrative, NOT an executed model result)

- **Public problem:** policy implementation varies between classes.
- **Primary lens:** policy implementation/local adaptation.
- **Alternative lens:** educator incentives, if actual institutional incentives and actions can be documented.
- **Question Q01:** what organizational capacity and frontline practices are associated with uneven implementation?
- **Caution:** current documents describe intended policy, not observed classroom practices or outcomes.

| Task | Actor | Observable evidence needed | Current state |
|---|---|---|---|
| Compare planned vs real execution | School management | policy/version, implementation schedule | policy supplied; identity/authority require verification |
| Compare front-line implementation | Class advisers and subject teachers | dated activity logs, workload records, interviews | missing |
| Detect ignored interests | Students and parents | consented interviews, accessible feedback | missing |
| Distinguish rival explanation | Other classes / baseline | baseline differences, resources, timing | missing |

**Tentative mechanism H01:** unequal workload and capacity may shape implementation consistency; no conclusion until observations support intermediate steps.

**Rival H02:** classes with different baseline risk profiles may receive different support without implementation failure.

**Next action:** verify source policy identity; plan ethical sampling and permissions; build actor/action/evidence matrix; do not create fictional respondents or apply causal labels to a before/after result.
